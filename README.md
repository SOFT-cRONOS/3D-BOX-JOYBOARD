# 3D Enclosure for Dual-Output Joystick Controller Board

A 3D-printable enclosure designed to house a joystick controller board with two output connectors.

The board can be used as a simple USB interface for building custom accessories for PC racing and flight simulators. For example, you can connect potentiometers to build custom sim racing pedals, handbrakes, gear shifters, buttons or other DIY simulator controls.

The enclosure protects the controller board and provides a cleaner, more practical solution for mounting it inside a custom simulator setup.

Example use

A common application is building a DIY pedal set:

Connect potentiometers to the joystick controller board.
Mount the potentiometers to custom 3D-printed pedals.
Connect the controller to the PC via USB.
Configure the axes in the simulator.
Use the pedals as throttle, brake and clutch controls.

The enclosure can also be adapted to other DIY simulator projects where a joystick controller board is used as an input interface.
